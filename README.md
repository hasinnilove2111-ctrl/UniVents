# UniVents

## University Event Management System

UniVents is a web-based platform designed to make university event management easier. It helps students discover upcoming campus events and register for them, while event organizers can create events, manage registrations, and track attendance in one place.

## Features

- **Browse Events** — Explore upcoming university events.
- **Search & Filter** — Find events by keyword or category.
- **Event Details** — View event descriptions, dates, times, venues, and seat availability.
- **Event Management** — Create, update, and remove event listings.
- **Student Registration** — Register for events easily.
- **Registration Management** — Track participants and manage event capacity.
- **Organizer Dashboard** — Manage events and view registered attendees.
- **Attendance Tracking** — Record and review event attendance.

## Technologies

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## Project Status

**Currently in development.**

We are building the frontend first, followed by backend integration and database functionality.

## Project Goal

Our goal is to create a simple, user-friendly platform that brings university events together in one place, making it easier for students to participate in campus activities and for organizers to manage events efficiently.
